# Wellness – יומן בריאות זוגי

אתר סטטי (HTML/CSS/JS, בלי שרת) למעקב יומי לשני פרופילים – חן וניר:

- **ארוחות** – בוקר / צהריים / ערב / נשנושים. בוחרים מוצרים מתוך כ-80 מזונות נפוצים (לפי קטגוריות או בחיפוש), מכוונים כמות ביחידות או בגרמים, והקלוריות של הארוחה מחושבות אוטומטית. מוצר שלא ברשימה אפשר להוסיף עם הקלוריות שלו, והוא נשמר תחת "שלי".
- **צעדים** – הזנה ידנית/כפתורים מהירים, חישוב מרחק וקלוריות לפי גובה ומשקל.
- **פעילות נוספת** – ריצה, שחייה, כושר ועוד (חישוב לפי ערכי MET).
- **סיכום יומי** – כמה אכלנו, כמה שרפנו (BMR לפי Mifflin‑St Jeor + צעדים + פעילות), מאזן קלורי.
- **BMI** – מתעדכן לפי המשקל שמוזן, עם סרגל צבעוני, טבלת קטגוריות וטווח המשקל האישי, וגרף מגמת משקל.
- **שנינו היום** – השוואה בין שני הפרופילים, וגרף של 7 הימים האחרונים.

## הפעלה
פותחים את `index.html` בדפדפן (או מפרסמים דרך GitHub Pages).
ההגדרות (שם, גובה, גיל, יעדים, צבע) נמצאות בכפתור ⚙.

## שמירה משותפת (דרך GitHub)
בלי הגדרה, הנתונים נשמרים רק בדפדפן (אפשר להעביר בין מכשירים עם ⚙ ← ייצוא / ייבוא).
כדי ששניכם תראו את אותם נתונים, האתר שומר אותם כקובצי JSON במאגר GitHub **פרטי** ומסנכרן כל חצי דקה.

**הגדרה חד-פעמית (רק בטלפון של מי שיש לו GitHub):**
1. יוצרים מאגר פרטי: https://github.com/new ← שם `wellness-data` ← לבחור **Private** ← Create repository.
2. יוצרים טוקן: https://github.com/settings/personal-access-tokens/new
   - **Token name:** `wellness`, **Expiration:** תוקף ארוך (למשל שנה)
   - **Repository access:** *Only select repositories* ← `wellness-data`
   - **Permissions → Repository permissions → Contents:** *Read and write*
   - **Generate token** ← מעתיקים את הטוקן (`github_pat_…`)
3. באתר: ⚙ ← "שמירה משותפת" ← מדביקים את הטוקן ← **חיבור**. הנתונים מהמכשיר עולים למאגר.

**בטלפון השני:** ⚙ ← **📲 שליחת קישור לטלפון השני** ← שולחים (למשל בוואטסאפ) ← פותחים את הקישור בטלפון השני. זהו.

**אבטחה:** הטוקן מאפשר גישה רק למאגר `wellness-data` ונשמר רק בדפדפנים שלכם – הוא לא נמצא באתר הציבורי.
קישור החיבור מכיל את הטוקן, אז שולחים אותו רק לבן/בת הזוג. אם הוא דלף – מוחקים את הטוקן ב-GitHub ויוצרים חדש.
האתר מסרב להתחבר למאגר ציבורי.

## צעדים מהשעון (Garmin / Samsung, באנדרואיד)
השעון ← אפליקציית השעון ← **Health Connect** בטלפון ← האפליקציה **HC Webhook** ← האתר (באותו טלפון).
האתר מושך את הצעדים בכל פעם שפותחים אותו, וכל 5 דקות כשהוא פתוח. מכאן הם עוברים גם לטלפון השני דרך השמירה המשותפת.

**1. מהשעון ל-Health Connect**
- **Garmin:** באפליקציית Garmin Connect ← הגדרות ← אפליקציות מחוברות ← **Health Connect** ← לאשר כתיבה של צעדים.
- **Samsung:** באפליקציית Samsung Health ← הגדרות ← **Health Connect** ← לאשר סנכרון צעדים.

**2. HC Webhook**
- מתקינים את **HC Webhook** מ-Google Play (קוד פתוח: github.com/mcnaveen/health-connect-webhook).
- מאשרים לה **קריאה** של Steps ב-Health Connect.
- מפעילים **Local HTTP server** (פורט 8787). אפשר להגדיר טוקן, ואז להזין אותו גם באתר.
- בהגדרות הסוללה של הטלפון: HC Webhook ← **ללא הגבלה**.

**3. בלי ספירה כפולה:** ב-Health Connect ← הרשאות אפליקציות ← לוודא שרק אפליקציית השעון (Garmin Connect או Samsung Health) מורשית **לכתוב** צעדים.
אחרת צעדים מהטלפון ומהשעון עלולים להיספר פעמיים.

**4. באתר:** פותחים ב-**Chrome** באותו טלפון ← ⚙ ← "צעדים מהשעון" ← מסמנים ← בוחרים של מי הטלפון.
אם Chrome שואל אם לאפשר גישה למכשירים ברשת המקומית – **לאשר**.
